# 奥氏体不锈钢腐蚀研究

铸造奥氏体不锈钢在 3.5 wt.% NaCl 环境下的点蚀行为研究：文献筛选与结构化、数据清洗、机器学习建模。

## 仓库内容

| 路径 | 说明 |
|---|---|
| `scripts/` | 数据处理与建模脚本（Python）：文献解析、去重、清洗、特征提取、建模 |
| `文献/` | 文献原文存放位置。**因版权与体积原因未包含在本仓库中**，仅保留空目录占位 |
| `0.xlsx` / `00.xlsx` / `1.xlsx` | `0.xlsx` 为原文初始信息表，`00.xlsx` 为重建版，`1.xlsx` 为清洗后的数据表 |
| `model_v1_*` / `model_v2_*` | 建模数据集、特征覆盖表与模型参数（JSON） |
| `口径基准_20261107.md` | **收录与清洗口径的唯一权威定义** |
| `*_2026110X.md` / `.csv` | 各批次入库校验、判级、去重、移动台账与清洗报告 |
| `*读图说明_*.md` | 从图件读取点蚀电位的作业说明与结果 |

## 数据口径概要

- 材料：熔炼—凝固路线（铸/锻/热轧/冷轧），排除增材制造、粉末冶金、焊接堆焊、表面改性
- 组织：奥氏体为主（奥氏体 + 少量 δ 视为奥氏体并标注）
- 介质：3.5 wt.% NaCl 及等价写法
- 目标量：点蚀电位 Epit，取阳极区拐点，不做 Tafel 外推
- 热处理：不收固溶/退火后再叠加敏化、时效、稳定化

完整定义见 `口径基准_20261107.md`。
